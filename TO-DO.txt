--------------------------------------------------------------
From your terminal, run:

    cd /home/mrahman/claude/projects/nh-cpt-practice

--------------------------------------------------------------
STEP 3 — Paste this prompt (edit the [bracketed] parts)
--------------------------------------------------------------

    In my project at /home/mrahman/claude/projects/nh-cpt-practice/,
    add a new personalized subsection called "[Topic Name]" using
    these new images I added to Phlebotomy_questions/:
    [filename1.jpeg, filename2.jpeg].

    Analyze each image and generate questions in the same style
    as the existing personalized section pages. Update the sidebar
    TOC on all personalized pages, add a card to the index.html,
    then commit and push.

--------------------------------------------------------------
WHAT CLAUDE WILL DO AUTOMATICALLY
--------------------------------------------------------------
Claude already has this project in its memory, so it will:

  1. Read each new image to understand its content.
  2. Generate ~20-30 appropriate questions
     (multiple choice, or fill-in-the-blank for diagrams).
  3. Create a new file:
         personalized_test_<topic>.html
     cloned from the existing section pages (same look + layout).
  4. Update the sidebar TOC on EVERY personalized page
     (so the new section appears in the left menu everywhere).
  5. Add a matching card to index.html under
     "Personalized Test — By Section".
  6. git commit + git push to origin/main.
  7. GitHub Pages auto-redeploys in about 1 minute,
     and the new section is live at:
         https://sujan00-git.github.io/nha-cpt-practice/

--------------------------------------------------------------
IF YOU WANT TO RUN IT YOURSELF (no AI)
--------------------------------------------------------------
Clone any existing personalized_test_*.html, then:
  - Change the <title> and header h1 to the new topic.
  - Replace the <img> src(s) with your new image filenames.
  - Replace the QUESTIONS array with your own questions.
  - Add the new link to the sidebar <nav> in ALL personalized_test_*.html files.
  - Add a new card to index.html under the "Personalized Test" group.
  - git add . && git commit -m "Add <topic> section" && git push
